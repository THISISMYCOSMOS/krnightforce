# split-witness

A members-only pass: the issuer commits to the member's birth year, and the member proves "born in 2006 or earlier" once per season. The holed version calls `birth_year()` and `pass_secret()` again for each use inside `redeem`. Every witness call is a separate private input (probe p29), so the year checked against the pass and the year compared with 2006 can differ, and the secret in the once-per-season tag need not be the secret in the pass. The engine's split-witness attack (T2) gives the later reads other values, the call still succeeds, and it reports `UNBOUND` for both (criterion 10). The fixed version reads each witness once and passes the value on. This is an assurance check, not a hiding check; it was added after the same mistake turned up in three other fixed scenarios (`docs/design-guide/lessons-first-build.md`, lesson 6).
